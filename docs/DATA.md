# Входные данные Spotify

## Файл и источник

Ожидается `Top_spotify_songs.csv` в корне проекта. Загрузка выполняется через `pandas.read_csv` с разделителем-запятой. Название файла и поля взяты из исходного ноутбука.

Точная ссылка на исходную выгрузку, её версия и условия распространения в первоначальном проекте не зафиксированы. CSV не включён в репозиторий. Для воспроизведения нужен исходный файл автора либо совместимая выгрузка; другая версия данных может дать другие результаты.

## Схема

| Группа | Столбцы |
|---|---|
| Идентификация | `spotify_id`, `name`, `artists`, `album_name` |
| Наблюдение в чарте | `country`, `snapshot_date`, `daily_rank`, `daily_movement`, `weekly_movement`, `popularity` |
| Релиз и длительность | `album_release_date`, `duration_ms`, `is_explicit` |
| Аудиохарактеристики | `danceability`, `energy`, `key`, `loudness`, `mode`, `speechiness`, `acousticness`, `instrumentalness`, `liveness`, `valence`, `tempo`, `time_signature` |

Числовые признаки должны читаться как числа, даты — преобразовываться через `pandas.to_datetime`. Для карты используются двухбуквенные коды стран. В коде глобальный чарт исключается по значению `All`.

## Обработка и ограничения

1. Ноутбук удаляет полные дубликаты строк и строки с любыми пропусками. Это может изменить представленность стран и треков.
2. Один `spotify_id` может встречаться многократно; число строк не равно числу уникальных песен.
3. ANOVA и t-тесты используются для исследования различий, без поправки на множественные сравнения. Причинные выводы по ним не делаются.
4. Для более строгой проверки гипотез нужны согласование фильтров с их формулировками, оценка размеров эффектов и учёт повторных наблюдений.

Числа в README и изображение превью извлечены из сохранённых выводов исходного ноутбука, а не из нового запуска.
